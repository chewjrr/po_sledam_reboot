# 🚶‍♀️ По следам

Мобильное приложение, которое **создаёт персонализированные пешеходные маршруты** по городу на основе вашего текстового запроса.

> Просто напишите, чего хотите — например:  
> _«Прогулка с видами на реку»_,  
> _«Места советской архитектуры»_,  
> _«Уютные кофейни и книжные»_ ☕  
> …и приложение построит оптимальный маршрут через интересные и релевантные точки ✨.

Этот репозиторий содержит **бэкенд-часть** приложения, реализованную в виде набора микросервисов.

---

## 🔐 Микросервис аутентификации (`backend/auth`)

Отвечает за регистрацию, вход и управление пользователями. Выдаёт JWT-токены, которые используются другими сервисами для авторизации запросов.

### Основные возможности
- Регистрация нового пользователя по email и паролю
- Авторизация с выдачей JWT-токена
- Получение списка пользователей (только для авторизованных)
- Валидация: уникальный email, пароль ≥6 символов

### Технологии
- **Фреймворк**: FastAPI  
- **База данных**: PostgreSQL  
- **Аутентификация**: JWT (HS256)  
- **Хеширование**: bcrypt (через `passlib`)  
- **Документация**: Swagger UI (`/docs`)
