# 🚶‍♀️ По следам

Мобильное приложение, которое **создаёт персонализированные пешеходные маршруты** по городу на основе вашего запроса 🗨️.  

Просто напишите, чего хотите — например:  
> _«Прогулка с видами на реку»_ 🌊  
> _«Места советской архитектуры»_ 🏢  
> _«Уютные кофейни и книжные»_ ☕📚  

…и приложение построит оптимальный маршрут через интересные и релевантные точки 🗺️✨.
